# Skills Index

Keep `AGENTS.md` concise. Put the expandable list of skills here.

## How to Use

- If a task phase has a matching skill (a `SKILL.md`), follow it.
- Prefer skill names over hard-coded absolute paths.

## Preferred Pipeline Skills

- Phase 0 (Ideation): `brainstorming`
- Phase 1 (PRD): `prd`
- Phase 2 (Planning): `prd-to-tasks`

## Where to Look (Repo-Relative First)

- `.agents/skills/**/SKILL.md`
- `.agent/skills/**/SKILL.md`
- `.claude/skills/**/SKILL.md`

If your environment provides user-level skills, consult those as well (location varies by setup).
