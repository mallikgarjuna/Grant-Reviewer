## Two Frameworks — Pick One

### Framework A: Product-Led (SaaS, tools, free signups)

| # | Section | Job |
|---|---------|-----|
| 1 | **Nav Bar** | Logo + links + sticky CTA |
| 2 | **Hero** | Headline + subheading + CTA — capture attention in < 3s |
| 3 | **Product Video** | 2-3 min demo — show don't tell |
| 4 | **Social Proof Bar** | Company logos / metrics strip |
| 5 | **Benefits** | 3-6 outcome-focused cards (benefits sell, features tell) |
| 6 | **How It Works** | 3-5 numbered steps |
| 7 | **Testimonials** | 2-3 quotes with specific results |
| 8 | **FAQ** | 5-7 accordion items removing objections |
| 9 | **Final CTA + Footer** | Repeat CTA + footer links |

*Source: @namyakhann / withsupafast.com*

---

### Framework B: Sales-Led (Digital products, paid offerings)

| # | Section | Job |
|---|---------|-----|
| 1 | **Hero** | Eyebrow → Headline → Subheadline → CTA → Trust Signals — *get email or get scroll* |
| 2 | **Success** | Checkmark → Confirmation → Deliverable list — *kill buyer's remorse* (conditional) |
| 3 | **Problem–Agitate** | 3 problems + agitation → personal transition — *make status quo painful* |
| 4 | **Value Stack** | 4 tiers → total value → your price — *make saying no feel stupid* |
| 5 | **Social Proof** | Header → 3 testimonials with specific results — *let others convince them* |
| 6 | **Transformation** | Quick Win → Compound → Advantage → 10x — *make outcome tangible* |
| 7 | **Secondary CTA** | Avatar stack → question headline → "Yes" button — *catch the scrollers* |
| 8 | **Footer** | Logo → Nav → Legal → Social — *professional legitimacy* |

*Source: J.A. Dickerson ($443K in digital products)*

## Brainstorm Integration Prompts

Use these questions during **Section 4 (Rough Idea Exploration)**:

**Q1**: Is this a product-led page (free signups) or sales-led page (paid conversion)?
→ Picks Framework A or B

**Q2**: Which 5 sections are essential for MVP? Which can wait for v2?
→ Scopes the first build

**Q3**: Do we have content for: product video? testimonials? social proof logos?
→ Identifies content blockers early

**Q4**: What is the single primary CTA action? (signup / email / purchase / waitlist)
→ Every section points toward this

**Q5**: What objections will visitors have? (→ shapes FAQ and Problem–Agitate)
→ Drives the persuasion sections
