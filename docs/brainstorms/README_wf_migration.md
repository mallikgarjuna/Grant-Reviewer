# Brainstorm Artifacts (WF)

This folder is for WF-based brainstorming artifacts created by the workflow system in `docs/workflow/`.

- Naming: `brainstorm-<WF-ID>-<slug>.md`
- Workflow reference: `docs/workflow/README.md`

Migration note:
- Legacy brainstorming notes currently live in `docs/brainstorms/` and are intentionally left in place until they are mapped to WF IDs.
