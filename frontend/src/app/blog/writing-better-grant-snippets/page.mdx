# How to Write Better Grant Snippets for AI Review

Most weak AI feedback is caused by weak input context.
If you want useful review cards, provide a snippet that is specific, bounded, and tied to one section intent.

## 1) Submit one section intent at a time

Avoid mixing background, methods, and impact arguments in a single paste.
One section objective produces clearer cards and fewer contradictory suggestions.

## 2) Keep references explicit

Use concrete terms for datasets, milestones, risks, and assumptions.
Vague claims produce vague feedback.

## 3) Use the review loop intentionally

Run one review, apply edits, then resubmit the updated snippet.
Treat each run as an iteration against rubric expectations, not a one-shot verdict.
